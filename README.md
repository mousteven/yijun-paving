# 宜軍企業社 官網

台中大里・景觀鋪面專業工班。承接營造廠分包之連鎖磚、植草磚、花崗石鋪面、路緣石安裝、石籠護坡工程。

## 狀態

**已上線（public repo + GitHub Pages）。**

`index.html` 為單頁自足網站（圖片以 base64 內嵌，零外部依賴），內容已包含真實聯絡資訊（電話、地址、統一編號）與 17 個實績案場，經過逐一查證（官方告示牌、業主/承造商名稱、業主本人口述確認）才收錄，細節見對話歷史。
