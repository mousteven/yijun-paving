# 宜軍企業社 官網（未公開版）

台中大里・景觀鋪面專業工班。承接營造廠分包之連鎖磚、植草磚、花崗石鋪面、路緣石安裝、石籠護坡工程。

## 狀態

**private repo，未開啟 GitHub Pages，頁面含 `noindex`。**
上線前需莊伯父（莊已毅）本人確認：

1. 電話、LINE、統一編號要不要放、放哪一組（目前是「待填入」）
2. 實績案場名稱與合作營造廠名稱可否公開
3. 照片內容有無不宜對外的畫面

確認後才轉 public 並開 Pages。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 單頁網站，零依賴，雙擊即可開 |
| `cases.js` | 案場資料（由 `build.py` 產生） |
| `photos/<slug>/` | 施工照片（長邊 1600px） |
| `photos/<slug>/t/` | 縮圖（長邊 640px） |
| `build.py` | 從「岳父工程學徒-公開版」挑案場、壓縮照片、清除 EXIF/GPS、產生 `cases.js` |
